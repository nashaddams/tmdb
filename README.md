# tmdb

[![JSR](https://jsr.io/badges/@nashaddams/tmdb)](https://jsr.io/@nashaddams/tmdb)
[![JSR score](https://jsr.io/badges/@nashaddams/tmdb/score)](https://jsr.io/@nashaddams/tmdb)

[TMDB](https://www.themoviedb.org/) API client based on the
[TMDB OpenApi](https://developer.themoviedb.org/openapi/).

## Usage

```ts
import { TmdbApi } from "@nashaddams/tmdb/v3"; // or
import { TmdbApi } from "@nashaddams/tmdb/v4";

const api = new TmdbApi("<TMDB_API_KEY>");
```

See [the docs](https://jsr.io/@nashaddams/tmdb/doc) for further details.
